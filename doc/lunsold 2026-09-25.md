# Pac-Man – Dev Diary – 2026-09-25

### What was done
- Fixed the name-input restart bug: the global `r`/`R` keydown handler in
  `controls.js` used to call `beginRound()` unconditionally, so typing an
  "R" into the name field on the game-over overlay would instantly restart
  the round. `handleKeydown()` now only triggers `beginRound()` when
  `!state.gameOverHandled`.
- Implemented cheat mode: new `GameState.cheats_enabled` flag plus
  `GameLogic.cheat_mode()` (toggled via the `cheat_activate` websocket
  action from yesterday's Konami-code detection), which sets
  `edible_until` to `float('inf')` so the player becomes permanently
  "edible"/invincible to ghosts while cheats are on, and back to `0.0`
  when toggled off. `game_logic_helper.py`'s super-gum pickup no longer
  overwrites `edible_until` while cheats are enabled.
- Added a second cheat: pressing Space now sends a `skip_level` action;
  the new `GameLogic.skip_level()` only does anything
  (`build_maze` + `next_level()`) while `cheats_enabled` is `True`.
- Reset `config.json`'s `lives` test value back to `3` (was `67` from
  testing the config loader).
- HTML/UI cleanup: renamed the "PLAY AGAIN" button on the game-over
  overlay to "HOME" and pointed it at `backToStartScreen` instead of
  `beginRound` (it was restarting the round instead of going back to the
  menu), fixed the pause menu's mangled "HOMEÜ" label, replaced the
  hero tagline with "lunsold & ascheufe", translated the remaining German
  strings in the settings/scoreboard/name-input screens to English, and
  fixed the settings screen's key-hint row (was showing "PAUSE" as the
  key instead of "P").
- Removed the old, unused `config.txt` (leftover from the
  mazegenerator CLI config, superseded by `config.json`).
- Wrote yesterday's and the two days before's missing dev-diary entries
  (`lunsold 2026-09-22/23/24.md`), renamed off the old plain-date
  filenames.

### Problems / bugs (fixed during the session)
- The game-over overlay's name input fighting with the global restart
  keybinding (see above) — anyone with an "r" in their name couldn't
  finish typing it without the round restarting under them.
- New bug noticed, not fixed yet: once cheat mode is active, pressing the
  Konami sequence again to turn it back off doesn't work on the first
  try — you have to enter the combination twice. Cause unclear so far.

# Pac-Man – Dev Diary – 2026-09-24

### What was done
- Ghost respawn (`c0d716a`): an eaten ghost now waits 5 seconds before it
  respawns. New field `Ghost.on_cooldown`, the respawn is done by the async
  task `LogicHelper._ghost_respawn()` (`asyncio.sleep(5)`). Ghosts on
  cooldown are skipped in `check_collision()` and don't block other
  ghosts' cells. `on_cooldown` is sent to the frontend and cooled-down
  ghosts are not drawn.
- Fixed the browser opening (`9bbecdd`): `webbrowser.open()` moved from
  `pac_man.py` into `server.py`'s `game_loop()`, so the browser only opens
  after the maze is loaded and the server is ready.

### Problems / bugs

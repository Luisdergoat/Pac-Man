# Pac-Man – Dev Diary – 2026-09-28

### What was done
- Player name max length reduced from 20 to 10 characters
  (`NAME_PATTERN` in `loader.py`, commit `3b29a65`).
- Renamed `pac_man.py` to `pac-man.py` (`9ed0d92`).
- Timer (`d9b76a5`):
  - `GameState.level_max_time` counts down by the tick length (0.3s) in
    `GameLogic.tick()` and is reset on restart and on `next_level()`. It
    is sent to the frontend.
  - `game_over` bool replaced by an `IntEnum` `State`
    (`ALIVE`, `DEAD`, `TIMEDOUT`), so the game can tell *why* it ended.
  - `respawn_after_hit()` now returns a `bool` instead of the string
    `"Game Over"`.
  - Config: keys renamed to `highscore_filename`, `points_per_pacgum`,
    `points_per_super_pacgum`; `level_max_time` added to the defaults.
    `_config_parser()` now starts from a copy of `DEFAULT_CONFIG`, so
    missing keys fall back to the defaults.

### Problems / bugs
- Config keys in the defaults did not match the keys the parser accepted
  (`highscore_file` vs `highscore_filename`, `points_per_gum` vs
  `points_per_pacgum`) -> unified.

### Next steps

# Pac-Man – Dev Diary – 2026-09-22

### What was done
- Translated all comments and docstrings in `backend/server.py` from German
  to English (started the general "everything in English" cleanup of the
  codebase).
- Added `pac_man.py`, a small cross-platform launcher script: it opens a
  terminal and starts `uvicorn` from there, with a `platform.system()` check
  (`Darwin` -> `osascript`/Terminal.app, otherwise `gnome-terminal`), so the
  project can be started with `python3 pac_man.py` instead of only via the
  macOS-specific `osascript` call baked into the Makefile.
- First test run to check whether the project actually runs on Linux, not
  just on macOS.

### Problems / bugs
- No blocking bugs found today, but the Linux path in `pac_man.py`
  (`gnome-terminal`) was untested/unverified – the venv activation inside
  the spawned terminal still assumed a venv that already exists.

### Next steps
- Continue translating the remaining backend files (`game_logic.py`,
  `loader.py`, etc.) to English.
- Actually verify the Linux startup path end-to-end (venv creation +
  activation from within `pac_man.py`), not just that a terminal opens.
